# Exercise 2

## Objective

Understand how a single example guides AI output.

## Prompt

Example:

Question: What is AI?

Answer:
AI refers to machines that can perform tasks requiring human intelligence.

Now answer:

What is Prompt Engineering?

## Technique

**One-Shot Prompting**

## Explanation

One example is provided before asking the AI to answer a similar question. The example helps the AI understand the expected format and style.
