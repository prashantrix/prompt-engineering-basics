## 📌 About

Prompt Engineering is the practice of writing clear and effective prompts to guide AI models toward producing accurate and relevant outputs.

This assignment covers the three fundamental prompting techniques:

- Zero-Shot Prompting
- One-Shot Prompting
- Few-Shot Prompting

It also includes prompt comparison, prompt improvement, and practical exercises.
